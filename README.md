# Rueda Barrial · TP N.º 5

Sitio de demostración para un taller ficticio de bicicletas. Abrí index.html
en el navegador. El sitio incluye filtros de servicios, preguntas frecuentes
y un generador de mensajes que funciona localmente.

Los tres archivos del proyecto deben estar en la misma carpeta. Para publicar
el sitio estático, index.html y taller.jpg deben quedar en la raíz del repositorio.
La foto de portada es ilustrativa y fue generada con IA.
